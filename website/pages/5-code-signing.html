Code signing policy.

What gets signed, who decides, and how a signed file ties back to the source.

Bezier is not signed yet. We are applying to the SignPath Foundation for free code signing of the Windows installer, and this is the policy the signing will follow. Until a certificate has been granted, no installer carries a signature, and this page says so.

What is signed

The Windows installers of a stable release: the setup program and the MSI. Nothing else is signed, and nothing that Bezier does not build itself: the one prebuilt component, the geometry kernel occt-wasm, is built from its public repository and is part of the installer, not signed on its own.

How a build gets there

  • The installers are built by the release workflow in the public repository, on GitHub's own build machines, from the source in the repository. The workflow and the build scripts are part of that source.
  • Every file of a release is listed with its SHA-256 sum on the release page. From the next release on, GitHub also attests which build made each file.
  • A signature is only requested for a release that has been approved by hand. Nobody else can approve one.

Who holds which role

  • Authors (may change the source without a second review): ProfessorEngineergit
  • Reviewers (review every change from someone who is not an author, such as a pull request): ProfessorEngineergit
  • Approvers (approve each signing request): ProfessorEngineergit

Bezier has one maintainer today, so one person holds all three. If others join, they are listed here with their role.

What the installer changes

Both Windows installers register Bezier as the program for STEP (.step, .stp), IGES (.iges, .igs), STL (.stl) and Bezier project (.bezier) files, and list Bezier among the installed apps with an uninstaller. The setup program installs for the current user and does not ask for administrator rights. If Microsoft's WebView2 runtime, which the app draws with, is missing (Windows 11 has it), the installer downloads it from Microsoft. Bezier does not start with Windows and installs no service.

Privacy

Bezier does not measure what you do and sends nothing on its own. What the app and this website do with data is on the privacy page.
