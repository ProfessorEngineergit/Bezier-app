await bezier.commands.add('Count the steps', async () => {
  const model = await bezier.model.read();
  await bezier.notify(`${model.steps.length} steps`);
});

{{icon:mcp}}Assistants that can see

Other CAD servers give an assistant one tool, “run this script”: fast, blind and a security hole. Bezier’s MCP gives an assistant that works on screen what it lacks: how the app works, where every control is, and the model to check each step against.

Made for the problems developers name.

Enforced, not promised

A plugin runs in a frame with no origin and one script, admitted by its hash. A call it was not granted is refused.

No restart loop

Save and the plugin runs again in the open editor, beside your model.

Stable references

Faces and edges keep their names through a rebuild, so a plugin can find the same face tomorrow.

An API that only grows

Version 1 gains calls and loses none. A change gets a new name and a year of overlap. Nothing stays “preview”.

No quotas

Plugins and MCP run on the person’s computer. Nothing is metered.

Review you can run

bezier-plugin check is the store’s own review, before you upload.

The whole source.

TypeScript and Rust, the tests, the benchmarks and every design decision with its reasons. Contributions go to the beta repository first.
