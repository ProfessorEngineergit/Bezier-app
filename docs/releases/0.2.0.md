Most of this is Windows. Bezier also knows now when a newer version is out, and can install it.

**Updates**
- The desktop app looks once at start whether a newer version exists and says so. Settings, Updates shows what changed and has an **Update now** button: Bezier downloads the new version, checks its signature, installs it and restarts. Nothing is installed unless you press it, and **Look at start** turns the look off.
- This is the first version that can do it, so installing 0.2.0 is a manual step once. From here on the app does it. A Linux install from a .deb or .rpm cannot replace itself; the AppImage can.

**Windows, and the same on every system**
- The orientation cube is one drawn canvas everywhere. The notches at its corners are gone, and faces, edges and corners can still be reached with the keyboard.
- Items: Shift-click picks every row in between, Ctrl or Cmd-click one row.
- "Reaches into Body 1 – Join, Cut, New body" goes away when you click somewhere else, and counts as New body.
- Space over a flat face squares the view up to it and starts a sketch there.
- Top, Front and the other views stay where you are unless the model is under the middle of the view.
- The hint next to the pointer while sketching was white on near white in dark mode.
- Glass and blur: a named Windows graphics adapter counts as hardware, so the blur is no longer switched off on machines that have one.
- `pnpm check` runs on Windows, and the repository keeps LF line endings.

**Still true**
- The apps are not signed yet, so macOS and Windows ask before they open Bezier the first time. Every file is listed with its SHA-256 sum in the SHA256SUMS files of this release, and from this release GitHub also attests which build made it.
